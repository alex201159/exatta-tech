Busca de vídeos no YouTube

Com essa chave preenchida, a página de Balanceiros passa a mostrar vídeos reais do YouTube ao pesquisar um equipamento. Sem ela, continua funcionando normalmente, só sem os vídeos externos.

Crie em console.cloud.google.com → APIs e Serviços → Credenciais → Criar credenciais → Chave de API, ative a YouTube Data API v3 pra esse projeto, e depois restrinja a chave (em "Restrições de aplicativo" → HTTP referrers) para exattatech.com/* e alex201159.github.io/* — assim ninguém mais consegue usar sua chave.
